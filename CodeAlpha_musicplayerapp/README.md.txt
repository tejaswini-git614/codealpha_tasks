🎵 Music Player App

A stylish and responsive music player built using HTML, CSS, and JavaScript. Enjoy your favorite songs with smooth controls and a clean UI.

Features

▶️ Play / Pause music
⏭️ Next / Previous controls
🔊 Volume control
📱 Responsive design
🎶 Playlist support

🛠️ Tech Stack

- HTML
- CSS
- JavaScript

📂 Project Structure

CodeAlpha_musicplayerapp/
│── index.html
│── style.css
│── script.js
│── songs/
│── README.md


How to Use

1. Open "index.html" in your browser
2. Click play to start music
3. Use controls to navigate songs
